# Jarvis / NumAI

Первый этап собственного ИИ: распознавание **одной арабской цифры 0–9**,
написанной тёмным маркером на светлом листе, через камеру. Результат выводится
в терминал. Разработка ведётся в ветке `getNumAI`.

## Voice agent (ветка `voice_agent`)

Офлайн-распознавание речи с микрофона: сказанные фразы печатаются в терминал.
Используется локальная модель Vosk (без облачных API).

```sh
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m voice
```

При первом запуске скачается маленькая русская модель (~45 МБ). Английский:
`python -m voice --lang en`. Выход — **Ctrl+C**.

В macOS разрешите микрофон приложению, запускающему Python
(**Системные настройки → Конфиденциальность и безопасность → Микрофон**).

Модель обучается **с нуля, со случайных весов**. Нет готовых нейросетей,
предобученных весов, OCR-сервисов, Ollama или обращений к API ИИ.
NumPy используется для математики, OpenCV — для камеры и обработки изображений.
ChatGPT, Cursor и DeepSeek могут помогать при разработке исходного кода;
для работы NumAI они не требуются.

## Быстрый запуск в VS Code / Cursor

Откройте папку Jarvis и встроенный терминал. Нужен Python 3.9–3.12.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m numai train
python -m numai camera
```

Если окружение и модель уже созданы в этой рабочей папке, достаточно:

```sh
source .venv/bin/activate
python -m numai camera
```

При первом обучении скачивается MNIST — около 12 МБ размеченных изображений,
**не готовая модель**. Файлы проверяются по контрольным суммам. Время обучения
зависит от компьютера. Интернет нужен для установки зависимостей и загрузки
изображений; после этого обучение и камера работают локально.

## Как показывать цифру

1. Напишите крупную цифру 0–9 чёрным маркером на белом листе без клеток и линий.
2. Запустите камеру. Программа автоматически ищет цифру по всему кадру.
3. Покажите лист в любой части кадра. Квадрат появится вокруг найденной цифры
   и будет менять положение и размер вместе с ней. Цифра должна быть видна целиком,
   с небольшим запасом белой бумаги вокруг; слишком мелкие символы пропускаются.
4. Держите лист ровно, при хорошем освещении, около секунды.
5. Терминал напечатает, например: `Вижу цифру: 7 (оценка модели: 96%)`.

Вывод появляется после пяти последовательных одинаковых предсказаний с оценкой
не ниже 85%. Повторяющиеся строки подавляются; после удаления цифры из кадра
её можно показать снова. Процент — оценка сети, а не гарантия правильности.
Пустые, обрезанные и некоторые неоднозначные изображения отбрасываются.
Зелёная рамка означает уверенное предсказание, жёлтая — найденный символ,
который сеть пока не распознала уверенно. При потере символа рамка исчезает,
а поиск по всему кадру продолжается. Несколько сопоставимых символов в кадре
считаются неоднозначным вводом.
Буквы и посторонние объекты всё ещё могут ошибочно распознаваться как цифры.
Текущая версия предназначена для одной цифры: многозначные числа не поддерживаются.

Маленькое чёрно-белое изображение в углу показывает вход нейросети.
Окно не зеркалируется, чтобы не переворачивать сами цифры.
Для выхода нажмите **Q / Esc** в окне или **Ctrl+C** в терминале.
Кадры не записываются на диск и не отправляются в интернет.

## Камера и диагностика

```sh
# Другая камера, если индекс 0 занят или выбран неверно
python -m numai camera --camera 1

# Только терминал; автоматический поиск по всему кадру остаётся включён
python -m numai camera --no-preview

# Проверка на фотографии: тёмная цифра на светлом фоне, без края листа
python -m numai image /absolute/path/to/digit.jpg

# Более строгий порог уменьшает число ответов, но не исключает ошибок
python -m numai camera --threshold 0.95
```

В macOS разрешите камеру приложению, запускающему Python (Terminal, VS Code
или Cursor), в **Системные настройки → Конфиденциальность и безопасность → Камера**.
Если разрешение не предлагается, запустите команду из обычного Terminal.
Закройте другие приложения, использующие камеру. В Linux проверьте доступ
пользователя к видеоустройству. `opencv-python-headless` для окна камеры не подходит.

## Что реализовано самостоятельно

- Полносвязная сеть: **784 → 128 → 64 → 10**, ReLU и softmax.
- Функция ошибки cross-entropy, обратное распространение ошибки и Adam.
- Случайная инициализация, обучение, сохранение и загрузка весов.
- Подготовка входа: выделение штриха, сохранение пропорций, масштабирование
  до 20 пикселей внутри изображения 28×28, центрирование по массе штриха.
- Автоматический поиск тёмного символа по всему кадру и квадрат вокруг него,
  меняющий положение и размер. Геометрические фильтры OpenCV находят область,
  затем собственная нейросеть распознаёт цифру; переобучение не требуется.
- Устойчивый вывод результата по нескольким кадрам.

Поиск рассчитан на одну тёмную цифру на чистом светлом листе при хорошем
освещении. Это не универсальный детектор объектов: сложный фон, тени и
посторонние надписи могут мешать поиску или давать ложные ответы.
Команда `image` по-прежнему принимает подготовленное изображение одной цифры.

MNIST содержит 60 000 обучающих и 10 000 тестовых изображений.
Из обучающих отдельно выделяются 5 000 для валидации. Обучение использует
55 000 изображений с небольшими случайными поворотами, сдвигами и изменениями
толщины штриха. Лучшие веса выбираются по валидации, затем проверяются на
10 000 тестовых изображений. Тестовые изображения не используются для обучения.

Точность на MNIST **не равна точности камеры**: освещение, почерк, резкость,
фон и толщина линии отличаются. Реальную камеру необходимо проверить на ваших
листах. Напечатанные цифры могут распознаваться хуже рукописных.

Первое локальное обучение дало **98,62% на тестовой выборке MNIST**.
Команды, условия, результаты и ограничения зафиксированы в [VALIDATION.md](VALIDATION.md).

```sh
# Повторно измерить точность сохранённых весов
python -m numai evaluate

# Новое обучение с нуля: явное разрешение заменить локальные веса
python -m numai train --epochs 15 --overwrite

# Короткая техническая проверка обучения, не полноценная модель
python -m numai train --epochs 1 --limit 1000 --model models/smoke.npz

# Проверки математики, изображения и поведения программы
python -m unittest discover -s tests -v
```

Веса сохраняются в `models/arabic.npz`, подробные метрики — в
`models/arabic.metrics.json`. Данные, веса и `.venv` исключены из Git:
на другом компьютере нужно повторить установку и обучение. Каждый запуск `train`
начинает обучение заново; продолжение с checkpoint пока не реализовано.

## Следующий этап: римские цифры

Римские цифры пока **не поддерживаются**. После проверки арабских цифр на реальной
камере следующий шаг — отдельные примеры символов I, V, X, L, C, D, M, обучение
их распознаванию с нуля, затем чтение последовательностей вроде IV и XII.
Для этого понадобится согласовать диапазон чисел и собрать соответствующие данные.
